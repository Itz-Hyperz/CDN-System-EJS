# CDN-System-EJS
A CDN System written in EJS that allows you to use ShareX to screenshot and upload files directly to your personal server. Comes with multiple user capability, you can set max storage limits, and its Discord and Passport integrated. All manageable through a custom made admin panel!

Refer to [the Knowledgebase](https://github.com/Itz-Hyperz/Knowledgebase) for EJS Website Install Instructions.
